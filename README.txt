PMM CONSTRUCTION — WEBSITE STARTER

FILES
- index.html   Main homepage content and Bootstrap layout
- styles.css   Custom colours, layout and responsive styling
- script.js    Small interactions (current year and mobile menu)

HOW TO PREVIEW ON WINDOWS
1. Extract the ZIP file into a folder, for example Desktop\PMM-Website.
2. Keep all three files in the SAME folder.
3. Double-click index.html. It should open in your browser.
4. For the best experience, keep an internet connection while previewing because Bootstrap and Google Fonts load from CDNs.

HOW TO EDIT
- Open index.html in Visual Studio Code, Notepad++, or Notepad.
- Change the company text, services, contact email and Managing Director profile.
- In the Leadership section, replace the portrait-placeholder block with an approved image, for example:
  <img src="images/paul-monoang.jpg" alt="Paul M Monoang, Managing Director" class="img-fluid">
  Put the image in a folder named images and adjust the CSS as needed.
- Change colours near the top of styles.css under :root.
- Do not rename styles.css or script.js unless you also update their references in index.html.

IMPORTANT BEFORE DEPLOYMENT
The service descriptions, company description and Managing Director responsibilities are starter copy, not verified company facts. Confirm them with PMM Construction and replace the sample email address with the official contact details. Add the company's real address, phone number, registration details, project photographs and approved biography if applicable.

This is a front-end website only. It does not include a database, admin dashboard, contact-form backend or hosting. The email link opens the visitor's email application.
